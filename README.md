# Portfolio en React

Bienvenue sur mon portfolio en React ! Ce projet a été créé dans le but de présenter mes compétences en développement web et mes projets personnels.

## Technologies Utilisées

Ce portfolio a été développé en utilisant les technologies suivantes :

- React : Une bibliothèque JavaScript pour construire des interfaces utilisateur interactives.
- HTML5 et CSS3 : Les langages de base pour la structure et le style des pages web.
- JavaScript ES6+ : La version moderne de JavaScript pour la logique et les interactions.
- React Router : Pour la navigation à travers différentes pages de l'application.
- Forms Spree : Pour permettre l'envoie de mail vers ma boite mail

## Fonctionnalités

Voici quelques-unes des fonctionnalités de mon portfolio :

- Présentation : Une brève introduction à propos de moi-même.
- Projets : Une section présentant mes projets récents avec des liens vers les dépôts GitHub ou vers une présentation plus détailler.
- Hobbys : Une section présentants mes loisirs.
- Compétences : Une liste de mes compétences techniques et outils que j'ai maîtrisés.
- Contact : Un formulaire de contact pour me contacter directement.

## Installation

Si vous souhaitez exécuter ce projet localement, voici les étapes à suivre :

1. Clonez ce dépôt sur votre machine locale.
2. Assurez-vous d'avoir Node.js installé sur votre machine.
3. Dans le répertoire du projet, exécutez `npm install` pour installer toutes les dépendances.
4. Enfin, exécutez `npm start` pour démarrer l'application. Elle devrait s'ouvrir automatiquement dans votre navigateur par défaut.
